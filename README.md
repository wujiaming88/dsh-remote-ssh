# dsh-remote-ssh

[English](./README_EN.md)

在 DSH 中通过 SSH 使用远端 Claude Code / Codex / Pi。当前版本为 **3.0.0-rc.50**：只实现当前 DSH 接口和完整远端 ACP，不包含旧版兼容层。

> 源码与离线测试通过不代表已完成真实 GUI 验收；明暗主题、焦点与像素级观感仍需在浏览器中人工确认。

## 当前能力

- **远端 Claude Code / Codex / Pi**：通过 SSH 或 Kerberos/GSSAPI 连接，在真实远端工作目录执行；本机 DSH 会话不被接管。
- **原生风格对话**：消息、工具行、输入区和附件展示采用 DSH 0.2.2-rc.5 分发源码的本地适配副本；紧凑显示操作名与路径，每轮仅在最终完成的助手回复上提供消息复制图标，在支持悬停的设备上随鼠标悬停或键盘焦点显示，无悬停能力设备保持可见。
- **完整交互流程**：支持流式输出、权限与表单确认、模型及模式选择、发送/停止、历史加载、重连，以及远端会话重命名、置顶和分叉。
- **附件与文件管理**：支持文本、图片及普通文件；普通文件在发送时上传并提供校验过的远端路径引用。另提供远端文件浏览、编辑、上传、下载和可选 Git worktree。
- **持久执行与消息发送**：新建的 durable 远端任务在本机断网或 Host 退出后继续由远端 owner 执行；支持原生插队及可撤回的排队消息。插件设置中的「运行时防止系统休眠」开启后，Host 会在本机持续持有防休眠断言（macOS `caffeinate -i -m -s`，Linux `systemd-inhibit`），无论是否有远端 turn 运行；锁屏但保持通电时可继续运行，关闭后释放。开启期间可能增加耗电。合盖睡眠、断电或系统强制睡眠仍可能中断本机 Host，但不会取消远端任务。升级前须确认旧版任务已结束，详见[断网恢复与升级边界](<docs/DURABLE_EXECUTION.md>)和[消息发送机制](<docs/MESSAGE_DELIVERY.md>)。
- **真实状态反馈**：显示本轮运行状态、用时、上下文占用和完成未读提示，不虚构协议未提供的统计。

当前版本 **3.0.0-rc.22** 已通过 **1005 项自动化测试**、**83 个客户端模块构建**与 **11 个远端 worker 模块构建**。真实 GUI 视觉与交互验收仍待完成。

[版本记录](./CHANGELOG.md) · [原生 UI 来源与适配边界](./docs/NATIVE_UI.md)

## 设计约束

1. **执行在远端。** ACP adapter、CLI、cwd、skills 和 MCP 位于同一台远端机器；本机只负责连接、持久化与界面。
2. **会话后端固定。** 工作区只保存连接与目录；在新会话中明确选择 Agent 和权限后持久化快照。同一工作区可分别创建 Claude / Codex / Pi 会话，已有绑定不变。
3. **本机会话零接管。** 未确认、查询失败或无关远端数据异常，不替换原生 Chat。插件不修改 `ctx.fs`、原生文件引用、终端配置、其他插件 DOM 或全局 fetch。
4. **真实生命周期。** 只在实际执行时记录原生 `turn/start + user/message`，完成后配对 `turn/end`；排队不冒充执行。原生新会话入口因此能区分已运行会话，不用占位消息或模拟点击。
5. **用户授权不自动代答。** 权限、表单与依赖准备都遵循明确的操作边界；唯一模型工具 `remote_session_status` 只查询执行者当前会话状态，不能启动 Agent、批准权限、回答表单或改变后端。
6. **没有兼容分支。** 不提供本地 adapter wrapper、旧 TUI/Shell、同步写回、旧 sidebar 接管、旧 schema 迁移或旧 DSH 版本兜底。

## 前置条件

- DSH `0.2.2-rc.5`，本机 Node.js 22+。
- SSH 私钥/ssh-agent 或 Kerberos/GSSAPI。Kerberos 用户先取得有效票据。
- 远端 Node.js 22+、npm、bash；文件和 worktree 功能需要 Python 3，worktree 需要 Git。
- 远端 CLI 的账号、代理、模型网关和额度可用。发现可执行文件不等于已验证模型访问。

运行环境使用固定版本：ACP SDK `2.9.1`、Claude adapter `0.109.1`、Codex adapter `2.9.0`、Pi adapter `pi-agent-acp 0.2.0`（从 GitHub tag 固定安装）。Pi 需要远端 Pi 1.6.1+。远端依赖只在确认安装计划后准备，默认目录 `~/.local/share/dsh-remote-acp/v1`，不使用 sudo、不修改 shell、不安装系统 Node。

## 使用流程

### 工作区与会话

1. **设置 → 远程 SSH**：新增 key/Kerberos 连接，或从 SSH config 选取配置后明确保存；测试连接。
2. **添加工作区 → 远端工作区**：只选择连接、目录，以及可选的独立 worktree，不选择 Agent。
3. 点击工作区的原生 **新会话**，在主会话页选择 **Claude Code / Codex / Pi** 和权限，再点击 **开始会话**。权限默认 Accept edits；Bypass 必须明确确认。未选择前不启动远端 Agent，也不绑定工作区默认值。
4. 缺少依赖时，查看「准备远端运行环境」计划并确认。错误留在对应远端页面，不偷偷改用本机 DSH 执行。

已选 Agent 后，主会话页顶部也提供 **新建会话**，可在同一工作区重新选择 Agent，并保留当前会话。该入口始终创建独立会话，避免原生工作区入口复用尚未发送消息的空白会话。

本机目录入口使用原生 DSH；远端工作区提供 Claude/Codex/Pi，不提供一个只能操作本机空目录的虚假 DSH 远端选项。本机目录选择仍调用 DSH 原生选择器。

### 对话与 Agent 能力

- Enter / 主发送按钮使用 DSH 原生 `busyEnter` 偏好，运行中默认排队；Ctrl/Cmd+Enter 使用另一种模式（默认插队），Shift+Enter 换行。Host 确认接收后清空草稿。
- 运行中主按钮会变为图标「停止」，代替原先的文字按钮；有待发送内容时主按钮仍用于发送/追加。
- 模型、思考级别和模式按 adapter 的实际配置展示，Host 确认后生效。
- 显式选择排队或原生插队；Codex 使用原生 `turn/steer`，Claude Code 使用 streaming input，Pi 使用原生 `steer`/`follow_up`，不用取消后重发模拟。Pi 的工具权限由 Pi 自身策略决定，插件权限选择不会限制 Pi 内置工具。原生样式队列可查看/撤回未执行消息；插队不支持或当前轮已结束时保留草稿，不悄悄改为排队。未知结果按原 ID/模式重试，详见[消息发送说明](<docs/MESSAGE_DELIVERY.md>)。
- 停止取消执行及待提交队列，不删除会话历史。
- 远端文件侧栏按 VS Code 风格显示语言/配置/图片图标；代码与配置默认语法高亮预览，Markdown 渲染、JSON 格式化，图片支持常见光栅格式，并可一键切回源码编辑。
- 支持权限请求，以及含单选、多选、自由回答的 form elicitation（包括 AskUserQuestion）。不支持的 schema 明确拒绝；不声明 URL/OAuth elicitation 支持。
- 输入 `/` 搜索实际提供的命令/skills；方向键选择，Enter/Tab 插入，Escape 关闭。指令列表随会话快照恢复，不会在长时间会话后丢失。
- 输入 `@` 浏览远端工作区，文本/图片引用仍在发送前读取有界快照；原生记录与实际发送使用同一份内容。此快照入口不读取压缩包等二进制内容；已在远端的普通文件可以直接在消息中提供路径。
- 附件支持「＋」选择、拖入和文件粘贴。文本/图片仍按原方式发送，图片须有能力支持；ZIP、PDF、Office、音视频等其他普通文件在点击发送后上传远端，再发送路径引用，不把二进制或 base64 塞进模型输入。
- 每条消息最多 16 个附件；文本合计 1 MiB、图片合计 2 MiB；其他文件单个 64 MiB、合计 256 MiB。普通文件保存在远端工作区 `.dsh-attachments/<会话隔离标识>/<上传ID>/<安全文件名>`，同名文件不会覆盖已有文件。能上传不等于远端已有相应解析工具。
- 上传中、已上传、失败均有反馈；失败保留草稿，重新发送复用上传ID和已确认结果，不重复发布。排队与插队复用附件授权和内容验证；原生插队只接受真实支持的内容，不支持时明确拒绝并保留草稿供另选排队。选择文件不会立即上传，插件不自动解压/执行；移除卡片不会删除已经上传的远端文件。
- 未发送的附件与上传回执仅留在当前页面进程内存，可随会话切换保留；刷新/关闭应用不恢复本地 File。文本草稿仍持久保存。远端引用在提交前校验大小和 SHA-256，被修改或移走时明确失败，不覆盖重传；若此前提交结果未知，应先核对会话历史，文件校验失败不代表此前消息未送达。
- 消息流按 DSH 原生风格展示：user 消息靠右气泡，assistant 正文全宽；思考、工具调用、子 Agent、计划、终端、会话消息、通知和上下文压缩都是轻量折叠行，保留回合/父子归属。

### 原生信息流与 composer

- 每个 turn 只有一个执行过程：思考、工具和执行中的阶段性说明统一收在其中；完成后仅最终回复独立展示，取消/中断不伪造最终答复。用户消息与告警仍独立可见，原始内容保留在过程里。对话流在流式输出时跟随尾部，向上翻阅会暂停跟随，历史预加载用稳定锚点保持位置；执行过程展开后采用有界滚动，避免长输出撑满页面。
- 工具行紧凑显示原生操作图标、操作名与路径/摘要，不重复显示路径；助手正文仅保留复制当前段落的图标。
- 思考展示为「思考图标 + 单行摘要 + 折叠箭头」，流式时有柔和扫光；展开后显示完整内容，流式更新不会重置展开状态。
- composer 下方是原生 ContextMeter 风格的 **上下文圆环**（点击展开：占用百分比、`~已用 / 容量` 与进度条）和 **会话统计**（回合数、已用时）；不再是右上角悬浮图标，也不会显示会话路径/ID。
- 工具/子 Agent/计划折叠行默认只显示摘要，展开才挂载 Diff、读取、终端或结构化结果；原始载荷统一收进次级「原始详情」。

终端卡是输出展示，不是交互式 TTY。命令列表仅代表 adapter 提供的命令，不模拟任意终端命令；子 Agent 可操作范围以协议实际暴露为准。

### 重命名、置顶与分叉

远端会话头部的原生「…」菜单提供 **重命名 / 置顶（取消置顶）/ 分叉**。

- **重命名**：名称写入同一个 DSH Session，并通过 ACP `session/set_title` 同步远端 CLI；采用返回的规范名称。原生侧栏重命名也会同步；异步失败通过原生通知提示，并可打开对应会话的同步状态。远端失败不假回滚已保存的 DSH 名称；界面显示 failed/unknown，不能把不确定结果当成“远端没改”。归档/冷会话通过 metadata-only 连接改名，不启动新会话或发送 prompt。
- **置顶**：完全使用 DSH 原生 WorkspaceRegistry 的持久置顶状态，不另建排序或远端 pin 概念。
- **分叉**：调用真正的远端 `session/fork`，创建独立的远端 ID/controller，然后发布继承历史的新 DSH 会话；不会把旧聊天拼成新 prompt，也不会仅复制空外壳。模型、思考级别和实际权限继承并校验，不提升权限，不继承置顶或待审批状态。

分叉只支持**最新完整上下文**；源会话必须无正在执行的回合、排队、审批或配置操作，归档会话先取消归档。两个会话仍共享原工作目录，不自动复制文件或创建 worktree。

原生列表右键额外提供「分叉远端会话」。DSH 自带的普通「分叉」及其快捷键只复制原生日志，因此在远端会话上被明确拒绝，请使用上述远端操作；本机 DSH 分叉不受影响。

分叉使用持久 operationId 和双阶段结果。远端已创建但本地发布失败时，重试恢复同一个 child，不再次 fork；结果未知时不自动重发，重新创建必须明确确认。继承历史带来源标记，不重演工具或重复记账原生 turn。

### 文件与 worktree

从会话右侧栏打开远端文件页，完成浏览、预览、编辑、上传、下载：

- 所有路径按真实会话工作区验证，拒绝越界。
- 保存以 SHA256 内容版本检查冲突，并原子发布；不无条件覆盖。
- 上传覆盖需要明确确认；下载上限 64 MiB。
- 未保存的编辑阻止关闭文件页或切换文件。
- PNG/JPEG/GIF/WebP 可以预览；HTML/SVG 不以内联可执行文档打开。

建区时可选「从 Git worktree 创建」，填写分支/基点并选择远端仓库。Host 创建并记录所有权后注册实际目录。移除 owned worktree 需要确认、先停止并归档相关会话；脏目录拒绝移除，不使用 force，不删除分支。普通解除工作区注册始终保留文件。

## 生命周期与存储

- 切换界面或关闭浏览器不因页面卸载取消远端任务。复用最近两个会话的浏览器订阅；后台会话 10 分钟未打开，或超出缓存数量时，回收对应订阅与消息缓存，保留远端任务。
- 连接保持机制：每 15 秒校验 Host 订阅心跳，45 秒无响应后断开浏览器订阅并以 1–10 秒退避续接。正常写缓冲背压等待 drain，不主动制造重连；每条订阅的待发送预算为 64 MiB，持续 10 秒无法排空才释放 HTTP 连接。历史及操作返回不覆盖较新的同游标控制状态；“续接/恢复会话消息同步”与“恢复远端 SSH 连接”分别提示，不把浏览器订阅状态当作 SSH 故障。心跳不代表远端 Agent 一定健康；运行时退出、权限撤销或身份变化仍显示错误，需明确重试。
- 视图切换和订阅回收后，未发送附件与待确认请求信息保留在当前页面的插件实例中；草稿文本仍写入本地存储。确认到达时只清除匹配的输入，不覆盖后续编辑；不确定的手动重试保留原请求 ID 与操作类型。页面关闭/插件卸载不保留内存中的附件与待确认元数据，身份变化或授权撤销会清理相应缓存。
- generation/seq 游标支持续接；历史按页读取，按回合与请求 ID 去重。支持向上滚动接近顶部时自动加载历史，不再需要常规“加载更早的消息”按钮；键盘和触摸也可触发，失败时保留明确重试入口。
- 补入历史时按当前阅读锚点恢复位置，不把尾部新输出的高度当作补入量；无进展页停止自动请求。短页/不可见事件页每次阅读手势最多连续补取三页，继续向上滚动可继续读取，避免后台无限拉取。
- Native Session 的记录与私有 ACP journal 都只记录真实发生的事实；缓存卸载不能伪造回合或取消远端任务。
- 归档遵循 DSH 原生 activity 检查，涵盖执行、排队、权限和表单。
- 本机断网或退出/重启 DSH 只断开连接；已接纳任务由独立远端 owner 继续执行。重开原会话连接同一执行并补取进展、权限与表单，不重新初始化 Agent 或盲目重发 prompt。需要审批时仍等待用户决定。
- 会话菜单新增“结束远端会话”，必须确认后才终止任务；确认关闭后保留只读历史、释放远端执行进程。未确认关闭的 owner 阻止删除其连接/工作区，避免丢失恢复入口。完整边界和本地测试证据见[断网与 Host 重启恢复](<docs/DURABLE_EXECUTION.md>)。

新记录位于当前 profile 的 `data/remote-acp/v3/`，有明确 schema/version。旧记录、目录和用户文件不会被删除，但本实现不读取或迁移旧格式；旧远端工作区需要重新添加。

## 代码结构

- [Host 装配](./lib/index.js)：路由、授权、生命周期、工具。
- [配置](./lib/config.js)、[SSH](./lib/ssh.js)、[工作区](./lib/workspaces.js)、[绑定](./lib/bindings.js)、[文件](./lib/files.js)。
- [ACP 编排](./lib/acp.js) 与 `acp-core/config/events/requests/store/transport` 模块。
- [原生回合记录器](./lib/remote-turn-recorder.js)：合法原生 Session 事件与去重 projection。
- [客户端入口](./src/client/index.js)：独立的设置、建区、会话、事件、文件、控件与样式模块。

客户端仅导入 Host React，不导入 Harness Client UI 包；基础控件与图标复制自当前 DSH 发布件，使用插件前缀本地适配，公开原生工厂继续直接复用。Markdown 视图采用原生排版，但 parser 仍为安全基本子集，不执行 HTML，不承诺完整 CommonMark 或像素级一致。复制来源、许可与差异见[原生 UI 适配说明](./docs/NATIVE_UI.md)。

侧栏状态通过公开 `sidebar.session.row.leading` 扩展位展示远端执行状态，使用一条共享、按会话授权的元数据流，不为每行启动或恢复 ACP。运行、等待审批/回答、完成、停止、异常和断开有独立说明；概览断流会降为未知，冷历史不会猜测成功。原生提醒保持优先；DSH 当前不在空白、归档、搜索结果及已有原生状态的行提供这个左侧扩展位。

## 开发与安装

```bash
npm run build
npm test
```

浏览器产物为 `lib/client.js`，只有一个模块 factory；不要直接编辑生成文件。候选版可通过 DSH **插件 → 添加插件 → 本地目录**安装。Git 提交和版本标签不等于 npm 发布；安装前请确认包的实际来源与版本。

HTTP 接口统一位于 `/remote-ssh/v3/`，仅使用单层 JSON 信封。它使用 DSH 当前连接认证与资源权限，现为 owner-only；不注册旧 URL、匿名 curl 授权或 LiveShare 权限兜底。

## 已知边界

- 长历史 journal 目前顺序扫描，无自动永久删除策略。
- 远端机器重启、owner/adapter 崩溃及杀死整个登录 cgroup 的策略不属于本机断线恢复；缺失 owner 时明确未知，不重建任务。需要 user service/linger 的环境须另行配置，不会隐式启用。持久化故障或额度耗尽会安全关闭并报告未知，不能承诺无限资源或跨 owner 崩溃继续执行。
- 不支持密码认证、ACP 原生音频内容块、任意 URI 附件、旧版数据迁移或自动为每个会话分配 worktree。音视频文件可以作为普通文件上传，但不保证远端具备解析能力。
- ACP 只上报 `used/size/cost`，没有原生的 system/tools/messages 上下文细分，也没有每轮 input/output/cache token、token/s 或 LLM/tool 耗时。界面展示当前上下文 token、单段占用比例、回合数与运行状态；会话时长位于统计详情，不冒充执行耗时。费用数据不在界面展示，不伪造缺失指标。
- 没有公开的通用 Markdown Factory，正文使用插件自有安全 Markdown 子集（不执行 HTML、不内联可执行文档），不承诺完整 CommonMark。
- DSH 当前没有可安全叠加的早期原生 prompt 拒绝接口。正常插件 UI 不切回 DSH 执行，但不能宣称 Host 能阻止 owner 绕过 UI 直接调用原生 `session/prompt`；未使用私有补丁或晚期假 guard。
- 真实 GUI 的明暗主题、焦点、键盘与像素级观感尚未经浏览器人工验收。
